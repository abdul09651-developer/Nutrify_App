# 🥗 Nutrify API

Nutrify API is a backend project developed to manage nutrition-related data through RESTful APIs. This project is built using Express.js, MongoDB, and Mongoose and serves as the backend foundation for a future full-stack Nutrify application.

## 🚀 Features

- REST API implementation
- MongoDB database integration
- Mongoose schema and model creation
- CRUD operations
- Structured backend architecture
- JSON request and response handling
- Ready for future frontend integration

## 🛠️ Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- Git & GitHub

## ⚙️ Installation & Setup

### Clone the repository

```bash
git clone https://github.com/abdul09651-developer/Nutrify_App.git
```

### Navigate into project folder

```bash
cd Nutrify_App
```

### Install dependencies

```bash
npm install
```

### Create a .env file

Add the following variables:

```env
PORT=3000
MONGODB_URI=your_mongodb_connection_string
```

### Run the server

```bash
npm start
```

or for development:

```bash
npm run dev
```

Server will run at:

```bash
http://localhost:3000
```
